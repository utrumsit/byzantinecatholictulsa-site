# St. Athanasius Byzantine Catholic Outreach of Tulsa — website

Plain HTML/CSS, no build step. Hosted on GitHub Pages from the `main` branch root.

## Editing
- All content is in `index.html`; styling in `style.css`.
- Edit on github.com (pencil icon) or locally, commit to `main`; Pages republishes in a minute or two.
- Search for `TODO` to find placeholders still needing real information.

## Calendar
The calendar is an embedded Google Calendar (`byzantinecatholictulsa@gmail.com`).
To change services/events, **edit the church Google Calendar** — the site updates automatically; no website edit needed.
Make sure the calendar stays shared publicly ("Make available to public") or the embed will be blank.
On phones the embed opens in agenda (list) view; visitors can toggle Month/Agenda.

## Donate
The Donate buttons point to `#donate` until the giving URL is ready. Replace both `href="#donate"` in `index.html`.

## Domain
No CNAME is configured yet. To move byzantinecatholictulsa.com here later, add a custom domain in repo Settings → Pages and update DNS.
